# SD Project (ISPY)
This contains all the test and the final computer vision program used on our Raspberry Pi 5 in our finished project. 
The project itself was a free-space optical surveillance system which was named Image Surveillance and Protection Yielder. 
It utilized a custom computer vision program, custom lens design, free-space optical design, custom output pcb board and data transmission program.
I worked on the computer vision part of the project which can be seen by all of my test programs and final program. 

## Features
* Real-time detection and tracking
* Detection/Tracking of a person using YOLO version 11
* Incrementation/decrementation of counter based on people in frame

## Languages and Libraries
* Python
* OpenCV
* Numpy
* YOLO

## Installation
### 1. Clone the repository
```bash
git clone https://github.com/CompDesigner/CV-Projects.git
cd CV-Projects
```
### 2. Install dependencies
```bash
pip install opencv-python numpy
```
Since YOLO is from ultralytics no installation is required
### 3. Run Script
Depending on your choice of which program you run  
```bash
python "SD Project/your choice.py"
```
Replace your choice with one of the file names  
Press `ESC` to exit the application
